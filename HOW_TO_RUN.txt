GDP-TO-GTP STRUCTURE PREPARATION - QUICK START
================================================

PURPOSE
Automate GDP-to-GTP replacement at one or more nucleotide-binding sites in
PDB structures. Candidate experimental GTP geometries are aligned and screened
for steric overlaps. Sites with residual overlaps are reported, not hidden.

REQUIREMENTS
- Python 3.8 or newer
- NumPy: python3 -m pip install numpy
- 'requests' is required only when rebuilding the reference library

INPUT
Place GDP-containing .pdb files in input/. GDP must be present as HETATM
records with the standard nucleotide atom names required by the script.
Input mmCIF files and multi-MODEL PDB ensembles are not supported.

RUN
Linux / macOS:  ./run.sh
Windows:        run.bat
Or, from the project directory:

  python3 gdp_to_gtp.py --input-dir input --out-dir output --cache gtp_all_rcsb_cache.tsv

OUTPUT
- output/<name>_GTP.pdb   : converted structure
- output/sites_<name>.csv : placement details for one input
- output/all_sites.csv    : results across input files

The 'unresolved' method in CSV reports means a placement was produced but
some steric overlap remains. Inspect the PDB and CSV reports before using
the structure for energy minimization or molecular dynamics.

REFERENCE LIBRARY
The default cache is gtp_all_rcsb_cache.tsv. The original tubulin-focused
cache remains available as gtp_tubulin_cache.tsv. Select either using --cache.

Full command-line options: python3 gdp_to_gtp.py --help
Scientific details and limitations: README.md
